🔍 Why Are Teenagers Struggling?

Research-backed insights into the three main drivers of youth mental health challenges

🪞

Distorted Information Processing

What they see shapes how they feel

The Problem:
  • Algorithm-driven feeds amplify highlight reels
  • Curated content creates false comparisons
  • Impossible standards for appearance & achievement
  • Negative content gets prioritized by algorithms
Impact: Upward social comparison → Lower self-esteem → Depression
Research Shows:
Each additional hour of social media use per year correlates with 0.41-unit increase in depression severity
📚 Research Details →
⚡

Compromised Coping Capacity

They can't recover from stress

The Problem:
  • Continuous phone interruptions fragment attention
  • Prevents sustained focus on coping tasks
  • Blue light & notifications disrupt sleep
  • No uninterrupted recovery time between stressors
Impact: Fragmented attention → Sleep loss → Emotional dysregulation
Research Shows:
Blocking internet access improves sustained attention, mental health, and subjective well-being (2025 PNAS study)
📚 Research Details →
🛡️

Reduced Protective Buffers

They're missing stress defenses

The Problem:
  • Social media replaces face-to-face connection
  • Less physical activity & outdoor time
  • Fewer hobbies and flow-state activities
  • Reduced opportunities to build competence
Impact: Social isolation → Physical inactivity → Loss of resilience
Research Shows:
Real relationships, physical activity, and hobbies are the strongest buffers against depression
📚 Research Details →
💡 Key Insight: These Are Interconnected

Bad information (distorted perception) meets a weakened capacity to process it (fragmented attention + poor sleep), while protective buffers (real friendships, activities) disappear. This creates a perfect storm. The good news: Each problem has a solution.

📚 How to Build This App - A Guide for Teenagers

Learn web development by understanding how this Mental Health Dashboard was built.

🎯 Part 1: What We're Building

A web application that displays real health data, visualizes trends with interactive charts, and provides treatment information from trusted medical sources.

Technologies: HTML5, CSS3, JavaScript, JSON, Bootstrap 5, Chart.js

Why no build tools? We're using vanilla JavaScript and CDN libraries so you can see exactly how everything works without abstraction layers.

📋 Part 2: Planning the Project

  1. Define the Problem: Youth need mental health data and treatment information
  2. Research Data Sources: CDC YRBS provides reliable public data
  3. Plan Features: Filters, charts, tables, multiple sections
  4. Sketch the UI: Always design on paper before coding!

💻 Part 4: How It Works

Data Flow:
1. HTML loads the page structure
2. JavaScript loads data from JSON files
3. User interacts with filters
4. JavaScript filters the data
5. Charts.js creates visualizations
6. Results display on screen

🔑 Key JavaScript Concepts

  • Classes: Organize code into reusable objects
  • Async/Await: Handle data loading without freezing the page
  • Event Listeners: React to user clicks and selections
  • DOM Manipulation: Update the page content dynamically
  • Filter & Map: Process arrays of data
  • Promises: Handle asynchronous operations

🎨 CSS Fundamentals

  • Flexbox & Grid for layouts
  • Media queries for responsiveness
  • Transitions & animations for interactivity
  • CSS variables for consistent styling
  • Shadow & border-radius for modern look

📊 Adding Features: Step by Step

  1. Create Data File - Define what information you need
  2. Load Data - Write code to fetch and parse JSON
  3. Filter Data - Create functions to find what users want
  4. Display Results - Render filtered data on screen
  5. Add Interactivity - Connect buttons/filters to functions
  6. Style & Animate - Make it look good and feel responsive

🧪 Testing Your Work

Testing Checklist:
✓ Open browser console (Ctrl+Shift+J) - watch for errors
✓ Test on mobile, tablet, desktop
✓ Test all filters and interactions
✓ Click all links - do they work?
✓ Use DevTools to inspect elements
✓ Check performance - is it fast?

🚀 Common Challenges

  • Data won't load: Check file paths, use console.log()
  • CSS not working: Clear browser cache, check specificity
  • Clicks do nothing: Check event listeners, verify elements exist
  • Slow performance: Profile with DevTools, optimize loops
