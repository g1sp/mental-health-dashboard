## Troubleshooting

**Chat tab missing?**
→ Hard refresh: Cmd+Shift+R (Mac) or Ctrl+Shift+R (Windows)

**API key modal not showing?**
→ Click Send button to trigger

**Invalid API key?**
→ Get new one from console.anthropic.com

**No response?**
→ Wait 1-3 seconds, check internet connection
